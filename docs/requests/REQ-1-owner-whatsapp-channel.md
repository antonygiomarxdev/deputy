# REQ-1: Owner instructs the agent over WhatsApp

Status: Open
Links: [Build the owner channel on WhatsApp](https://github.com/antonygiomarxdev/deputy/issues/147), [Write the owner-channel decision and chain changes](https://github.com/antonygiomarxdev/deputy/issues/146)

## Summary

The owner wants to add the agent to their own WhatsApp and give it instructions there, not only in the agent's own window. It matters because the owner is often away from the computer.

Last change: 2026-11-24, first draft from the owner's words

## Who asked and when
The owner, 2026-11-24, in a Claude Code session.

## What they said
> cosas que si deben venir, agregarte a vos por whatsapp para dar instrucciones, que compile y no tenga que estar levantando nada nadie, investiguemos de este tipo de productos que mas cosas podemos agregar

## The problem behind it
Today the owner can only talk to the agent in the agent's own session. Whether the owner's go for a draft may also travel over WhatsApp is open and touches principle 1.

## Evidence
Comparable products: OpenClaw and Claude Code channels (Telegram) let the owner command the agent from chat with an allowlist and a pairing code. Meta Business Agent and the SaaS inboxes do not. Source: competitive scan, 2026-11-24.

## Decision
Open. Waits for the owner.
