# REQ-12: Modes as packaged skills

Status: Open
Links: [Offer Deputy modes as packaged skills](https://github.com/antonygiomarxdev/deputy/issues/160)

## Summary

Deputy offers modes, each a packaged skill: an assistant that helps answer customers, an analyst for business data, more later. Every mode stays scoped to the owner's business.

Last change: 2026-11-24, first draft from the owner's words

## Who asked and when
The owner, 2026-11-24, in a Claude Code session.

## What they said
The owner asks for different modes, for example an assistant mode that helps answer customers and an analyst mode, with the skills inside each mode.

The owner asks that everything to do with the owner's business can be kept and maintained there, inside the modes.

## The problem behind it
One agent session mixes answering customers with analysing the business. The owner wants them as separate modes.

## Evidence
Unknown. Related: REQ-4 (scope) and REQ-10 (an analyst mode needs the insights tool).

## Decision
Open. Waits for the owner.
